    Admin Guide¶

    This guide is for the IT or platform team that sets up AI Firewall in an organisation.

    AI Firewall has two parts:

    Part What it is Who uses it
    The server (control plane) A self-hosted service where your security team sets policy, watches how AI tools are used and reviews audit records. It runs on one Linux server that you own. IT and security administrators
    The agent A small program on each employee's computer. It checks requests to AI tools and applies the policy. Installed on every managed computer

    All data stays in your environment. The server is installed and run by you.

    The installation at a glance¶

    1. Get the server ready and the network open (see Prerequisites).
    2. Run the installer script install.sh. It installs Docker and the aifw command.
    3. Run aifw preflight, then aifw setup. Setup asks a few questions and does the rest.
    4. Save the sign-in details that setup shows, then sign in to the admin portal.

    It takes about 20 minutes on a prepared server.
